# فاز ۱ — PWA و اعلان

## وضعیت موجود
زیرساخت یادآورها، Jalali و جدول‌های اعلان از قبل در پروژه وجود داشتند و دوباره ساخته نشدند. این فاز فقط لایه PWA را تثبیت کرده است.

## تصمیم فنی
- Service Worker مستقل /sw.js بدون Workbox اجرا می‌شود تا وابستگی تجاری یا بسته جدید لازم نباشد.
- src/sw.ts منبع TypeScript است و public/sw.js نسخه قابل‌تحویل مستقیم است.
- ثبت Service Worker به‌صورت دستی انجام می‌شود؛ وابستگی virtual:pwa-register حذف شده است.
- اعلان iOS فقط در حالت نصب‌شده PWA فعال است.
- کلید خصوصی VAPID هرگز در کلاینت یا ریپو قرار نمی‌گیرد؛ از Vault موجود Supabase استفاده می‌شود.
- اعلان آزمایشی از send-push استفاده می‌کند.

## دارایی‌ها
اجرای python scripts/generate-pwa-icons.py شش آیکون PWA و badge را در public/pwa می‌سازد. آیکون اپل در index.html استفاده می‌شود.

## نصب iOS
Safari → اشتراک‌گذاری → افزودن به صفحه اصلی → بازکردن برنامه از صفحه اصلی → فعال‌کردن اعلان.
