# فاز ۲ — سازمان‌ها و ارتباط بین شرکت‌ها

در این فاز، ارتباط بین دو سازمان یک مجوز صریح است و تا زمانی که وضعیت ارتباط پذیرفته نشده باشد، همکاری بین سازمانی مجاز نیست.

قواعد:
- مشاهده فقط برای اعضای فعال یکی از دو سازمان.
- درخواست فقط توسط مالک یا مدیر سازمان مبدأ.
- پذیرش فقط توسط مالک یا مدیر سازمان مقصد.
- تعلیق و لغو فقط توسط مالک یا مدیر یکی از طرفین.
- حذف فیزیکی مسدود است؛ لغو با deleted_at ثبت می‌شود.
- وضعیت accepted تنها وضعیت معتبر برای مجوز همکاری بین سازمانی است.
- تریگر مهمان ممیزی، تریگر تغییر وضعیت، ممیزی و جلوگیری از تغییر طرفین فعال هستند.
