# File scanning\n\nCustoms OS uses **بررسی ایستای محلی** (local static inspection) for chat attachments. It is defense-in-depth and does not claim antivirus equivalence. ClamAV is not installed in the current architecture.\n\nChecks include magic bytes, executable extensions/magic, PDF active-content markers with hex-escape normalization, Office macro extensions, ZIP path traversal, encrypted archives, nested archives, archive limits and internal SHA-256 lookup. Downloads must remain blocked while security_status is scanning or error.\n\nThe scanner is claimed with PostgreSQL FOR UPDATE SKIP LOCKED and retries at most three times before marking both file_scans.status and chat_attachments.security_status as error.\n\nRequired fixture set: clean PDF, PDF with JavaScript, clean DOCX, DOCM, ZIP containing an EXE, and an EXE renamed to PNG. A live fixture run is required before declaring the scanner end-to-end verified.\n
